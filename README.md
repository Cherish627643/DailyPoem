# 诗词集

一款个人使用的古诗词鉴赏工具，支持随机阅读、搜索诗人/诗词，帮助你随时随地品味经典诗词之美。

## ✨ 功能介绍

### 已实现

- **随机阅读**：每次刷新获取一首新的诗词，邂逅不期而遇的经典
- **搜索诗人**：按诗人姓名搜索，快速找到目标作品
- **搜索诗词**：支持按标题、正文内容检索诗词
- **诗人详情页**：点击诗人名字，查看该诗人的全部作品

### 计划中

- **收藏功能**：收藏喜欢的诗词，随时翻阅
- **搜索历史**：记录搜索记录，方便快速回访
- **每日推荐**：每天打开自动展示一首诗词
- **夜间模式**：适配深色主题，舒适阅读

## 🛠️ 技术栈

- **语言**：Kotlin
- **框架**： XML
- **数据库**：Room
